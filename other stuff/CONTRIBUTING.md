# Contributing
Sponsorship Portal would take *literal* **years** to make without other people, so please contribute if you want to help and get this out in a reasonable time frame.
## Guidelines:
### Don't troll
It's just not funny or cool, and just delays the project further (and also makes this a crap ton more annoying to do!!)
### Actually help
This one is easy, honestly. This rule is in line with the previous rule, but just more broad. Don't switch things around back and forth constantly. If it doesn't help push the project forward, *just don't do it at all!*
### Don't be a jerk
This rule is probably the easiest. Don't be rude, annoying, or a jerk in disucssions, the wiki, and in the code.

**More rules will be added if needed.**
